    Cách hoạt động

    4 bước từ dữ liệu đến báo cáo

    1. 1Bạn gửi dữ liệu

      Sheet, file hoặc link Lark Base.

    2. 2AI nhận & kiểm tra

    3. 3Làm sạch dữ liệu

      Không làm sạch được thì báo lỗi, bạn gửi lại.

    4. 4Xuất kết quả

      Xuất HTML · Dashboard · Báo cáo (BC).
